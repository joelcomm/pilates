# Mat Daily

Daily mat Pilates workouts with light weights. Pick a focus (abs, arms, legs and glutes, or full body), a length (15 to 60 minutes) and an intensity, then follow along with pictures and a guided timer. Every session can be logged in the built-in tracker.

It is a plain HTML, CSS and JS web app with no build step. It works offline and can be added to a phone's home screen. Workout logs are stored in the browser only.

To run it locally, serve this folder with any static server, for example `python3 -m http.server`.
